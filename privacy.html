개인정보처리방침

shorts-uploader · 시행일 2026년 10월 20일

무엇을 하는 앱인가

shorts-uploader 는 운영자 본인의 유튜브 채널에 본인이 만든 영상을 올리고, 그 채널의 정보를 확인·관리하는 개인용 도구입니다. 다른 사람에게 제공하지 않습니다.

쓰는 구글 사용자 데이터

  • YouTube 업로드 권한(youtube.upload) — 운영자 채널에 영상을 올리고 제목·설명·공개 범위를 정하는 데만 씁니다.
  • YouTube 계정 관리 권한(youtube) — 올리기 전에 대상 채널이 맞는지 확인하고, 운영자 채널의 소개·배너 같은 정보를 관리하는 데만 씁니다.

저장과 공유

  • 로그인으로 받은 인증 정보는 운영자의 컴퓨터에만 저장합니다. 이 앱의 서버는 없습니다.
  • 구글 사용자 데이터를 다른 사람이나 회사에 넘기거나 팔지 않습니다. 광고·분석·AI 학습에 쓰지 않습니다.
  • 이 앱이 구글 API 에서 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따릅니다.

권한 철회와 삭제

Google 계정 → 서드파티 액세스에서 언제든 이 앱의 권한을 없앨 수 있습니다. 권한을 없애면 저장된 인증 정보는 더 이상 쓸 수 없고, 운영자가 컴퓨터에서 지웁니다.

Privacy Policy

shorts-uploader · Effective October 20, 2026

What this app does

shorts-uploader is a personal tool that uploads the operator's own videos to the operator's own YouTube channel and manages that channel's details. It is not offered to other users.

Google user data it uses

  • YouTube upload (youtube.upload) — only to upload videos to the operator's channel and set their title, description and visibility.
  • YouTube account management (youtube) — only to confirm the target channel before uploading and to manage the operator's channel details such as its description and banner.

Storage and sharing

  • Credentials obtained at sign-in are stored only on the operator's computer. The app has no server.
  • Google user data is never transferred or sold to anyone, and is not used for advertising, analytics or AI training.
  • This app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at Google Account → Third-party access. Once revoked, the stored credentials stop working and are deleted from the operator's computer.
